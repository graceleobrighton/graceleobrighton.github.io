The History Helper is now class-only

July 29, 2026

A quick update for anyone in class: the History Research Helper now has its own private access link. It used to be open to anyone with the web address — now it's locked, and only people I share the link with can open it.

What the History Helper is

It's a chatbot I built to help with history research. Right now it's loaded with primary sources about the Chinese Labour Corps in World War I — memoirs and newspaper pages from 1916–1919. You can ask it to:

  • Find the exact page in a document that talks about something
  • Check whether a fact you want to use is actually true
  • Suggest areas of your writing you could improve
  • Catch grammar mistakes and typos
  • Search the web for more background beyond our documents

When it answers, it shows you exactly where the information came from and highlights the matching part of the original document, so you can always check its work.

The rules haven't changed

The whole point is to help you do your own work — not to do it for you. So it will not write an essay or fully rewrite one for you, and if someone tries, it says so on screen and reports it to the teacher. Finding sources, checking facts, and fixing your own writing are all fair game.

How to get in

The tool is now behind a class access link — a bit like a shared Google Doc where only people with the link can open it. I'm not posting the link here on purpose, because this page is public and the whole point is to keep the tool for our class.

To get access, just ask me for the class link (or the access code). One tap on the link and you're in — it remembers you afterwards, so you only do it once.

If your link ever stops working, it means the code was changed — come find me and I'll get you the new one.

For teachers

There's a teacher view for managing classes and seeing who's joined. You can open it at either of these addresses — they're the same site, just two names for it:

  • studenthistoryaionly.com/teacher
  • history-research-helper.onrender.com/teacher

The first is our custom web address and the second is where the app is actually hosted; whichever you use, you land on the same teacher dashboard (it'll ask for the teacher key).

Happy researching!
