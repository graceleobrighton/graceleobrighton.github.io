How to join the History Helper

July 29, 2026

If you're in my class, here's everything you need to start using the History Research Helper. It only takes a minute, and you only have to do it once.

Step 1 — Get the class link from me

The tool is private, so you need our class link to open it. I'll share it with you in class (or on our class page). It will look something like this:

https://studenthistoryaionly.com/?key=pebble-otter-97

That's just an example — use the real link I give you. Please don't post it anywhere public; it's only for our class.

Step 2 — Open the link

Tap or click the link. That's it — you're in. The tool remembers you for about a month, so next time you can just go straight to the site without the link.

If you ever see a lock screen asking for an "access code," type the code from our class link (the part after ?key=) and press Enter.

Step 3 — Type your name

You'll be asked for your name. Put your real name so I can see who's using the tool. Then read the quick rules and tap "I understand — start."

Step 4 — Start researching

You can ask the helper to:

  • Find the exact page in a document about your topic
  • Check whether a fact you want to use is true
  • Suggest ways to improve your own writing
  • Catch grammar mistakes and typos
  • Search the web for more background

When it answers, it shows you exactly where the information came from, so you can always check its work. You can also ask follow-up questions — it remembers what you were just talking about.

Remember the rules

The helper is here to help you do your own work. It will not write or fully rewrite an essay for you, and if someone tries, it says so and lets me know. Finding sources, checking facts, and fixing your own writing are exactly what it's for.

If your link stops working

Sometimes I change the class code (for example at the start of a new term). If your link suddenly shows the lock screen, just come find me and I'll give you the new one.

That's all — happy researching!
